Review Games: setup guide

Grade 12 · Unit 4 · Week 10 · Session 4 · Review and Project. Two live games and the School Map Lab: Memory Map (warm-up) and Structure Showdown (wrap-up).

Firebase is already set up and config.js is already filled in. Just do step 1: create a new repository called G12W10S4 and upload these files. Scores for these games are kept separate from all your other games.

In these games and the lab
  • Mystery topic in the warm-up: every right answer flips three letters of REVIEW AND PROJECT.
  • Sort-into-groups cards: linear or non-linear, and queue / tree / graph for real problems.
  • Order the tiles (a BST in-order walk) and tap the Python line that finds a shorter route.
  • School Map Lab (lab.html): Part 1 inserts values into a BST, walks it in-order and searches for 60. Part 2 draws the school map as a weighted graph, runs BFS, plans a route and finds the shortest path (and a new one when a corridor closes).

1Put the games on GitHub Pages

  1. On github.com click New repository. Name it exactly G12W10S4, set it to Public, and create it.
  2. Click uploading an existing file. Drag in all the files from this folder (not the folder itself). Click Commit changes.
  3. Open Settings → Pages. Under Build and deployment choose Deploy from a branch, branch main, folder / (root), and click Save.
  4. Wait 1–2 minutes and refresh. The games are now at https://emanjeha.github.io/G12W10S4/
  5. If you use a different repository name, open config.js and change SITE_URL to match. (The lesson page also uses this address for its QR codes.)

2Suggested lesson flow

Step 1Warm-up game (Memory Map). Open board.html?game=warmup, students scan and join, press Start.
Step 2Journey, then the review: Line, tree or graph? (Session 1), Tree review (Session 2) and Graph review (Session 3).
Step 3Pick the structure: students choose and justify a structure for 6 real problems.
Step 4The project brief (MIS School Map) and the project code in Python.
Step 5School Map Lab. Show the QR code or write the link on the board: https://emanjeha.github.io/G12W10S4/lab.html. Follow progress on results.html.
Step 6Wrap-up game (Structure Showdown), 3D recall video, recap and exit ticket. Press Switch to Structure Showdown, Start, then Show answers.

3Run it in class

Classroom screenOpen https://emanjeha.github.io/G12W10S4/board.html?game=warmup on the classroom computer and press Full screen on the projector or smart board. The QR code and join link appear on the left.
StudentsOne device each (or one per pair). They scan the QR code or open the link, type their name and press Join.
StartPress Start game. Everyone sees 3-2-1-GO, then the questions. The board re-ranks live and shows each move in the Live moves feed.
EndResults open by themselves when everyone finishes. Or press End game to stop and show the podium and the hardest questions.
Wrap-upPress Switch to Structure Showdown. After it ends, press Show answers to read every exit ticket.
Next classPress New round (click twice). This clears the board for a fresh group.

4Good to know

  • Practice mode: without internet access to Firebase, students can still play, but nothing appears on the board.
  • Refreshing is safe: if a page reloads, the student continues where they were .
  • Late players can join at any time while the game is live.
  • Scoring: 100 points per correct answer, up to 50 for speed, and a streak bonus (+20, +40, +60) from the 3rd right answer in a row. In the warm-up, cracking the mystery topic is worth +200.
  • Keyboard: on a laptop, students can answer multiple-choice with keys 1–4 or A–D and press Enter for the next question.
  • Changing questions: edit questions.js in GitHub (pencil icon) and commit. The top of that file explains each question type.
  • Who can control the board: anyone who opens board.html can press Start or End, so don't share that link with students.

5If you ever need a new Firebase

  1. Go to console.firebase.google.com, create a project, then Build → Realtime Database → Create Database (location europe-west1), test mode.
  2. In Rules, paste {"rules":{"sessions":{".read":true,".write":true}}} and click Publish.
  3. In Project settings → Your apps → </>, register a web app and copy the values into config.js.
